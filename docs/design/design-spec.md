### 2.5 配色规则

- R1 页面白底（`#FFFFFF`）为主，浅灰区块（`#F5F7FA`）交替节奏；深色区块（`#0B2B52`）仅页脚与首页 Hero/宣传视频区。
- R2 正文一律 `#3E4C59`，标题 `#1F2933`；彩色文字仅用于链接与标签，正文段落禁止彩色。
- R3 全站可访问性底线 WCAG AA：正文 ≥4.5:1，大字号（≥18px 或 14px 粗体）≥3:1（规范 §6.7）。
- R4 医疗场景禁用红/绿做装饰（保留给语义态），避免「告警感」。

## 3. 字体与字号阶梯

### 3.1 字体族

```css
--font-sans-zh: "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
--font-sans-en: "Inter", "Helvetica Neue", Arial, sans-serif;
--font-sans: var(--font-sans-en), var(--font-sans-zh); /* 英文优先回退，中文兜底 */
```

- 中英文共用同一阶梯；英文站 `lang="en"` 时渲染 Inter，中文站渲染 PingFang/雅黑。
- 数字与认证标识（NMPA/FDA/CE/ISO13485）用 Inter 的 `font-feature-settings: "tnum"` 等宽数字。

### 3.2 字号阶梯（移动优先，桌面值 = ≥1024px）

| 令牌 | 移动 (<768px) | 桌面 (≥1024px) | 行高 | 字重 | 用途 |
|---|---|---|---|---|---|
| `--text-display` | 32px | 48px | 1.2 | 700 | 首页 Hero 主标题 |
| `--text-h1` | 28px | 40px | 1.25 | 700 | 内页 H1（页横幅标题） |
| `--text-h2` | 24px | 32px | 1.3 | 600 | 区块标题 |
| `--text-h3` | 20px | 24px | 1.35 | 600 | 卡片组标题、侧边栏标题 |
| `--text-h4` | 17px | 19px | 1.4 | 600 | 卡片标题 |
| `--text-body-lg` | 16px | 18px | 1.7 | 400 | 首段/摘要 |
| `--text-body` | 15px | 16px | 1.7 | 400 | 正文（中文最小 15px，保证可读） |
| `--text-small` | 13px | 14px | 1.6 | 400 | 辅助文本、面包屑、页脚 |
| `--text-caption` | 12px | 12px | 1.5 | 400 | 标签、图注、ICP 备案行 |

- 字重仅三档：400 / 600 / 700；禁止 300 细体用于正文（低对比风险）。
- 段落最大行宽：中文 34em、英文 68ch（`--measure`）。

## 6. 组件状态规范

> 每个组件给出：默认 / 悬停 / 激活 / 焦点 / 禁用 /（适用时）加载 / 错误 / 空。焦点环全站统一：`outline: 2px solid #3584E4; outline-offset: 2px;`（键盘可达，规范 §6.7）。

### 6.1 按钮（Button）

| 变体 | 默认 | 悬停 | 激活 | 禁用 |
|---|---|---|---|---|
| 主按钮 | 底 `#1A5FB4` 白字，radius-sm，padding 12px×24px，字号 16px/600 | 底 `#123F77`，shadow-sm | 底 `#0B2B52`，下移 1px | 底 `#C9D1D9` 字 `#7B8794`，`cursor:not-allowed` |
| 次按钮 | 白底，边框 1px `#1A5FB4`，字 `#1A5FB4` | 底 `#EFF5FC` | 底 `#D8E7F8` | 边框/字 `#C9D1D9` |
| 品牌渐变按钮（仅首页 CTA） | `--gradient-brand` 白字 | 亮度 +8% + shadow-md | 亮度 −8% | 同主按钮禁用 |
| 文字链接按钮 | 字 `#1A5FB4` 下划线 none | 下划线出现 + 字 `#123F77` | 字 `#0B2B52` | 字 `#7B8794` |

- 加载态：按钮文字左侧 16px 旋转指示器，按钮宽度不变、禁用点击。
- 最小点击目标 44×44px（触屏可达）。

### 6.2 导航（Header / Nav）

- 桌面页头：白底，高 72px，sticky；滚动超过 8px 后加 `--shadow-sm`。Logo 左（高 40px），主导航居中，右侧搜索图标 + 语言切换胶囊。
- 导航项：16px/500（用 600 档实现为 600），`#3E4C59`；悬停字变 `#1A5FB4` + 底部 2px `#00B3A6` 指示条滑入（150ms）；当前页项字 `#1A5FB4` + 常显指示条。
- 下拉（产品中心 ▾ / 资源 ▾）：白底卡片 radius-md + shadow-md，单列最小宽 240px，项高 44px；悬停项底 `#EFF5FC`。
- 移动页头：高 56px，右侧汉堡钮（44×44px）；抽屉从右滑入（250ms），宽 min(320px, 85vw)，深底 `#0B2B52` 白字；抽屉内语言切换置底固定。

### 6.3 卡片（Card：产品 / 视频 / 下载 / 证书）

| 状态 | 样式 |
|---|---|
| 默认 | 白底，radius-md，border-default，图 16:9 裁切，标题 `--text-h4` `#1F2933` 2 行截断，摘要 `--text-small` `#7B8794` 2 行截断 |
| 悬停 | 上移 4px + shadow-md（250ms），图片放大 1.03 倍（容器 overflow hidden） |
| 激活/按下 | 上移 2px，shadow-sm |
| 焦点 | 整卡一个 `<a>`，焦点环同全局 |
| 视频卡 | 图左下角 28px 圆形播放图标（底 `rgba(11,43,82,.72)` 白三角），右下时长角标 `--text-caption` 白字深底 |
| 下载卡 | 左侧 40px PDF 图标 + 文件名 + 文件大小；悬停同卡片 |
| 空占位卡 | 见 §6.6 |

### 6.4 表单（在线留言 / Feedback）

| 元素 | 规范 |
|---|---|
| 输入框 | 高 48px，radius-sm，border-default，padding 12px×16px，字号 16px（防 iOS 缩放） |
| Label | 输入框上方，`--text-small` 600 `#3E4C59`；必填 `*` 用 `#C53030` |
| 焦点 | 边框变 `#1A5FB4` + 外发光 `0 0 0 3px #D8E7F8` |
| 错误 | 边框 `#C53030` + 下方 14px 错误文案 `#C53030`，前置错误图标；错误摘要锚定到首个错误 |
| 成功 | 表单区替换为成功面板：`--color-success-50` 底 + 成功图标 + 「我们已收到您的留言」 |
| 提交按钮 | 主按钮全宽（移动）/ 自适应宽（桌面），提交中进入加载态 |
| 无 JS 降级 | 原生表单提交到后端端点（渐进增强，规范 §6.6） |

### 6.5 页脚（Footer）

- 深底 `#0B2B52`，字 `#C9D1D9`，标题白字 16px/600。
- 四列栅格（桌面）：关于我们 / 产品中心 / 资源 / 联系方式 + 公众号二维码（96×96px，白底 padding 8px 圆角 8px）。
- 链接悬停：白字 + 下划线。社交图标（LinkedIn/Facebook）24px，`#C9D1D9` → 悬停 `#00B3A6`。
- 底部条：上边框 `1px solid rgba(255,255,255,.12)`，`--text-caption`，含 ICP 备案链接（悬停下划线）。
- 移动：单列堆叠，各组可折叠（手风琴，默认展开第一组）。

### 6.6 状态组件（空 / 错误 / 加载）

| 状态 | 规范 |
|---|---|
| 空态（产品分类无产品、新闻空列表） | 居中面板：浅灰插图区（48px 线性图标 `#7B8794`）+ 标题 `--text-h4` + 说明 `--text-body` `#7B8794` + 可选行动按钮（如「联系我们获取资料」次按钮）。新闻空态文案：「暂无动态，敬请期待」/ "No news yet. Stay tuned." |
| 加载中 | 骨架屏：卡片用 `--color-neutral-200` 圆角矩形 + 微光扫过动画（1500ms 循环，reduced-motion 时静态） |
| 加载失败 | 错误面板：`--color-error-50` 底 + 错误图标 + 「内容加载失败，请重试」+ 重试次按钮 |
| 视频加载失败 | 播放器区域内嵌错误提示 + 海报图保留 |
| 404 页面 | 居中：大字号「404」（`--text-display` `#D8E7F8`）+ 说明 + 「返回首页」主按钮 + 双语提示 |

### 6.7 面包屑 / 轮播 / 灯箱 / 视频播放器

- 面包屑：`--text-small`，当前页 `#7B8794` 无链接，上级 `#1A5FB4`；分隔符 `/` `#C9D1D9`，间距 8px；移动横向可滚动不换行。
- 首页轮播：高 移动 320px / 桌面 480px；指示点 8px 圆点 `#FFFFFF` 40% 透明、当前 24px 胶囊 `#00B3A6`；左右箭头 44px 圆形半透深底；自动播放 5s，悬停暂停，支持触摸滑动；无 JS 降级为横向滚动容器。
- 灯箱（证书/荣誉图）：遮罩 `rgba(11,43,82,.85)`，图最大 90vw×85vh，关闭钮 44px 右上，Esc/点击遮罩关闭，焦点圈禁在灯箱内。
- 视频播放器：原生 `<video>` + 自定义海报（16:9）+ 中央 64px 播放钮（深底白三角，悬停变 `--color-accent-500`）；`preload="metadata"`；控制条用原生以保证键盘可达。

## 7. 响应式断点（与规范 §3.6 一致，禁止组件自定）

| 令牌 | 值 | 关键布局变化 |
|---|---|---|

## 8. 图标与图片

- 图标：线性 SVG，stroke 2px，尺寸 16/20/24/40px 四档；语义色随上下文（默认继承文字色）。
- 图片比例：卡片 16:9；Hero 21:9（桌面）/ 4:3（移动）；证书图 3:4 竖版居中于 16:9 容器（contain，不裁切）；Logo 不拉伸。
- 图片格式：构建期输出 WebP + JPEG 回退（C6）；`alt` 必填且来自字典（§6.7）。

## 9. 品牌调性两方向（**待客户确认**）

| | 方向 A：医疗信任蓝（本文采用） | 方向 B：科技深色 |
|---|---|---|
| 主色 | `#1A5FB4` 医疗蓝 + `#00B3A6` 科技青点缀 | `#0B2B52` 深海军蓝大面积铺底 + 青蓝渐变主视觉 |
| 气质 | 专业、可信、克制，贴合医院/代理商受众（400+ 三甲医院客户） | 前卫、炫酷，贴近科技展陈风格 |
| 风险 | 相对保守 | 医疗采购决策者偏保守，深色大底阅读长文（公司简介）体验差 |
| **推荐** | ✅ **推荐 A**：受众是医院科室与经销商，信任感优先；用渐变与动效表达「先进」，而非牺牲可读性 | — |

> 确认流程：评论中标注待客户确认；若客户选 B，仅需替换 §2 主色/深浅底分配，字号/间距/组件状态不变。
