# 天泓医疗新版官网 — 视觉设计规范（Design Spec）v2

> **版本 v2.0 ｜ 2026-10-09 ｜ 设计定稿（客户 2026-10-09 于 SHAR-51 拍板 direction-a-plus）**
> 状态：**已定稿，为唯一事实源**。v1.0（旧企业蓝 `#1A5FB4`）已作废。
> 用途：开发照此实现、视觉验收官照此截图比对。所有数值为强制值，不接受近似。
> 依据：`docs/design/prototypes/direction-a-plus/styles.css`（定稿原型，`:root` 令牌整块移植）、`docs/content-inventory.md`、`docs/architecture.md`、`PROJECT_STANDARDS.md` §3.6（断点基线）。

## 1. 设计令牌总览

所有令牌最终落在 `src/styles/variables.css` 的 CSS 变量（架构约定 C9：组件内禁止自定义新变量）。本文给出令牌名 + 具体值，开发一一对应。**令牌数值来源为 direction-a-plus 原型 `:root` 块，整块移植零改动**；语义别名（`--color-*` / `--space-*` / `--text-*`）以 `var()` 引用源令牌，不重复定义数值。

### 2.5 配色规则

- R1 页面白底为主，浅灰区块（`#F4F8FA`）交替节奏；深色区块（`#063845`）仅页脚、统计条、Hero 叠加。
- R2 正文一律 `#3D4F59`，标题 `#1B2A32`；彩色文字仅用于链接、Kicker、标签与强调，正文段落禁止彩色。
- R3 全站可访问性底线 WCAG AA：正文 ≥4.5:1，大字号（≥18px 或 14px 粗体）≥3:1。
- R4 医疗场景禁用红/绿做装饰（保留给语义态）；橙红 `#E75306` 为品牌强调，用于「+ 号 / Live 点 / 进度」等小面积，禁止大面积铺底。

## 3. 字体与字号阶梯

### 3.1 字体族

```css
--font-sans: "Inter", "Helvetica Neue", Arial, "PingFang SC", "Microsoft YaHei", "Noto Sans SC", sans-serif;
```

- 中英文共用同一族（英文优先，中文兜底）。
- 数字与认证标识（NMPA/FDA/CE/ISO13485）用 `font-feature-settings: "tnum"` 等宽数字。

### 3.2 字号阶梯（移动优先，桌面值 = ≥1024px）

| 令牌 | 移动 (<1024px) | 桌面 (≥1024px) | 行高 | 字重 | 用途 |
|---|---|---|---|---|---|
| `--fs-display` | 32px | 48px | 1.25 | 700 | 首页 Hero 主标题 |
| `--fs-h2` | 24px | 32px | 1.25 | 700 | 区块标题（h1 内页横幅 / h2 区块标题共用） |
| `--fs-h3` | 19px | 22px | 1.25 | 700 | 卡片组标题 |
| `--fs-body-lg` | 16px | 18px | 1.75 | 400 | 首段/摘要/Hero lead |
| `--fs-body` | 15px | 16px | 1.75 | 400 | 正文（中文最小 15px） |
| `--fs-small` | 13px | 14px | 1.6 | 400/600 | 辅助文本、Kicker、面包屑、页脚 |

- 字重仅三档：400 / 600 / 700；禁止 300 细体用于正文（低对比风险）。
- 段落最大行宽：中文 34em、英文 68ch（`--measure-zh` / `--measure-en`）。

## 5. 圆角、阴影、边框、动效

| 令牌 | 值 | 用途 |
|---|---|---|
| `--r-sm` (`--radius-sm`) | 4px | 按钮、输入框、标签 |
| `--r-md` (`--radius-md`) | 8px | 卡片、图片容器 |
| `--r-lg` (`--radius-lg`) | 12px | 横幅卡、视频播放器容器 |
| `--r-pill` (`--radius-pill`) | 999px | 胶囊标签、语言切换器、Hero 指示点 |
| `--shadow-sm` | `0 1px 2px rgba(6,56,69,.08)` | 卡片静态 |
| `--shadow-md` | `0 4px 14px rgba(6,56,69,.10)` | 卡片悬停、下拉 |
| `--shadow-lg` | `0 12px 32px rgba(6,56,69,.16)` | 灯箱、模态 |
| `--dur` (`--duration-base`) | 180ms | 统一动效时长（悬停/切换） |
| `--ease` | `cubic-bezier(.4, 0, .2, 1)` | 统一缓动 |

- 动效规则：仅 transform/opacity 动画；`prefers-reduced-motion` 时全部动效降级为即时切换。
- 悬停位移：卡片上移 3px（原型 `.p-card:hover` `translateY(-3px)`），滚动显现上移 18px（`.reveal`）。

## 6. 组件状态规范

> 每个组件给出：默认 / 悬停 / 激活 / 焦点 / 禁用 /（适用时）加载 / 错误 / 空。焦点环全站统一：`--focus-ring`（`2px solid #0D8FB5`）+ `--focus-offset`（2px）。

### 6.1 按钮（Button）

| 变体 | 默认 | 悬停 | 激活 | 禁用 |
|---|---|---|---|---|
| 主按钮 `.btn-primary` | 底 `#0D8FB5` 白字，radius-sm，min-height 44px，padding 0 24px，字号 15/16px 600 | 底 `#0A6E88` + shadow-sm | 深一级 | 底 `#CBD6DB` 字 `#71838D`，`cursor:not-allowed` |
| 次按钮 `.btn-outline` | 白底，边框 1px `#0D8FB5`，字 `#0D8FB5` | 底 `#EFF8FB` | 底 `#D6EEF5` | 边框/字 `#CBD6DB` |
| 文字链接按钮 | 字 `#0D8FB5` 下划线 none | 下划线出现 + 字 `#0A6E88` | 字 `#063845` | 字 `#71838D` |

- 加载态：按钮文字左侧 16px 旋转指示器，按钮宽度不变、禁用点击。
- 最小点击目标 44×44px（触屏可达）。

### 6.2 导航（Header / Nav）

- 桌面页头：白底 `rgba(255,255,255,.9)` + `backdrop-filter: blur(10px)`，高 72px，sticky，下边框 1px `#E3EAEE`。
- 导航项：15/16px 500，`#3D4F59`；悬停/当前字变 `#0D8FB5` + 底部 2px `#0D8FB5` 指示条（180ms）。
- 下拉（产品中心 ▾ / 资源 ▾）：白底卡片 radius-md + shadow-md，单列最小宽 240px，项高 44px；悬停项底 `#EFF8FB`。
- 移动页头：高 56px，右侧汉堡钮（44×44px）；抽屉从右滑入（180ms），宽 min(320px, 85vw)，深底 `#063845` 白字。

### 6.3 卡片（Card：产品 / 视频 / 下载 / 证书）

| 状态 | 样式 |
|---|---|
| 默认 | 白底，radius-md，边框 1px `#E3EAEE`，图 16:9 裁切，标题 `--fs-h3` `#1B2A32`，摘要 `--fs-small` `#71838D` |
| 悬停 | 上移 3px + shadow-md（180ms），图片放大 1.03 倍（容器 overflow hidden） |
| 激活/按下 | 上移 1px |
| 焦点 | 整卡一个 `<a>`，焦点环同全局 |
| 视频卡 | 原生 `<video>` `preload="none"` + 播放控制；占位/失败降级为 `--c-neutral-100` 底 + 播放图标 |
| 下载卡 | 左侧 PDF 图标 + 文件名 + 文件大小；悬停同卡片 |
| 空占位卡 | 见 §6.6 |

### 6.4 表单（在线留言 / Feedback）

| 元素 | 规范 |
|---|---|
| 输入框 | 高 48px，radius-sm，边框 1px `#E3EAEE`，padding 12px 16px，字号 16px（防 iOS 缩放） |
| Label | 输入框上方，`--fs-small` 600 `#3D4F59`；必填 `*` 用 `#C53030` |
| 焦点 | 边框变 `#0D8FB5` + 外发光 `0 0 0 3px #D6EEF5` |
| 错误 | 边框 `#C53030` + 下方 14px 错误文案，前置错误图标；错误摘要锚定到首个错误 |
| 成功 | 表单区替换为成功面板：`#E6F6EE` 底 + 成功图标 + 「我们已收到您的留言」 |
| 提交按钮 | 主按钮全宽（移动）/ 自适应宽（桌面），提交中进入加载态 |
| 无 JS 降级 | 原生表单提交（mailto: 结构化邮件，ADR-005） |

### 6.5 页脚（Footer）

- 深底 `#063845`，字 `#D6EEF5`，标题白字 16px/600。
- 四列栅格（桌面）：关于我们 / 产品中心 / 资源 / 联系方式 + 公众号二维码（96×96px，白底 padding 8px 圆角 8px）。
- 链接悬停：白字 + 下划线。社交图标（LinkedIn/Facebook）24px。
- 底部条：上边框 `1px solid rgba(255,255,255,.14)`，12px 半透明白字，含 ICP 备案链接。
- 移动：单列堆叠。

### 6.6 状态组件（空 / 错误 / 加载）

| 状态 | 规范 |
|---|---|
| 空态（产品分类无产品、新闻空列表、宠物康复视频空） | 居中面板：浅灰插图区（`--c-neutral-100` 底 + 40px 图标 `#71838D`）+ 标题 `--fs-h3` + 说明 `--fs-body` `#71838D` + 行动按钮（「联系我们」次按钮） |
| 视频加载失败 | `<video>` 区降级为 `--c-neutral-100` 底 + 播放图标，不整块空白（ADR-003 §5.2 onerror 兜底） |
| 404 页面 | 居中：大字号「404」（`--fs-display` `#D6EEF5`）+ 说明 + 「返回首页」主按钮 |

### 6.7 面包屑 / 轮播 / 灯箱 / 视频播放器

- 面包屑：`--fs-small`，当前页 `#71838D` 无链接，上级 `#0D8FB5`；分隔符 `/` `#CBD6DB`；移动横向可滚动不换行。
- 首页轮播：Hero 高 min(88vh, 760px)；指示点 8px 圆点 `#FFFFFF` 40% 透明、当前 24px 胶囊 `#E75306`；左右箭头 44px 圆形半透深底；自动播放 5s，悬停暂停，触摸滑动；无 JS 降级为横向滚动容器。
- 灯箱（证书/荣誉图）：遮罩 `rgba(6,56,69,.85)`，图最大 90vw×85vh，关闭钮 44px 右上，Esc/点击遮罩关闭。
- 视频播放器：原生 `<video>` + `preload="none"` + poster；控制条用原生保证键盘可达。

## 8. 图标与图片

- 图标：线性 SVG，stroke 2px，尺寸 16/20/24/40px 四档；语义色随上下文。
- 图片比例：卡片 16:9；Hero 视频/图 覆盖全屏；证书图竖版居中。
- 图片格式：`alt` 必填且来自字典；素材经 `assets.ts` 唯一出口（ADR-003），`img/video` 一律 `onerror` 兜底。
