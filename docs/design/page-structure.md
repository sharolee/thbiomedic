# 天泓医疗新版官网 — 页面结构说明（Page Structure）

> 版本 v1.0 ｜ 2026-10-04 ｜ 交互设计师小欧（SHAR-23）
> 配套：`docs/design/design-spec.md`（数值规范）、`docs/design/acceptance-checklist.md`（验收要点）。
> 页面清单以 `docs/content-inventory.md` §1/§2 为基线；路由结构以 ADR-002（`/zh/`、`/en/` 镜像）为准。
> 每页给出：区块顺序 → 交互说明 → 空态/异常态 → 备注。

---

## 0. 全站通用

### 0.1 页面骨架（每页一致）

```
Header（sticky，72px/移动56px）
  ├ Logo（左，点击回当前语言首页）
  ├ 主导航：首页 | 关于我们 | 产品中心 ▾ | 资源 ▾ | 新闻动态 | 联系我们
  ├ 搜索图标（点击展开搜索框，见 0.3）
  └ 语言切换器（右端，见 0.2）
Breadcrumbs（仅内页，页横幅下方）
main（页面区块，见各页）
Footer（四列 + 备案条）
```

### 0.2 语言切换器（验收重点）

- 位置：桌面在页头最右端（搜索图标右侧）；移动在抽屉菜单底部固定。
- 形式：胶囊 `--radius-pill`，当前语言高亮（底 `#1A5FB4` 白字），另一语言纯文字。显示「中 / EN」（中文站）或「CN / EN」（英文站当前项高亮）。
- 行为：点击切换到**同语义页面**的另一语言版本（ADR-002 §5.4 / 规范 6.3），禁止跳首页；产品详情等动态页若对端不存在，回退到同分类列表页并在目标页顶部显示一次性提示条（`--color-warning-50` 底）：「该页面暂无英文版本，已为您跳转到分类页」。
- 键盘可达，焦点环同全局规范。

### 0.3 站内搜索

- 桌面：点击页头搜索图标 → 页头下方滑出搜索条（高 64px，白底 shadow-sm），输入框自动聚焦，Esc 关闭。
- 移动：抽屉内顶部搜索框。
- 结果页：`/zh/search/?q=...`，结果按「产品 / 页面 / 视频」分组卡片列出；空结果 → 空态面板（图标 + 「未找到与"X"相关的内容」+ 建议改关键词），并提供「联系我们」次按钮。
- 无 JS 降级：表单 GET 提交到结果页（静态构建下由客户端过滤预生成的搜索索引 JSON；无 JS 时提示「搜索需要启用 JavaScript」）。

### 0.4 空态 / 异常态通用规则（规范 §6.6：每页覆盖加载、空、错误三类状态）

| 场景 | 表现 |
|---|---|
| 列表为空（产品分类、新闻、视频栏目） | design-spec §6.6 空态面板 |
| 图片加载失败 | 占位底 `--color-neutral-100` + 居中 40px 图片图标 `#7B8794` + alt 文案可见 |
| 视频加载失败 | 海报保留 + 覆盖错误提示与重试按钮 |
| 表单提交失败 | 表单顶部错误条（`--color-error-50` 底）+ 字段级错误保留输入值 |
| 404 | 独立 404 页（双语），见 design-spec §6.6 |

## 1. 首页 `/zh/` `/en/`

**目标**：3 秒传达「骨科康复 + 放疗固定 + 宠物康复」三条品牌线 + 建立信任（认证/医院客户）。

区块顺序：

1. **Hero 品牌轮播**（Carousel，client:visible）
   - 3 张品牌卡：宝力易® 骨科康复 / 固德易® 患者固定 / 宝力谊® 宠物康复。
   - 每卡：背景图 + 左侧文案区（品牌名 `--text-h3`、主标题 `--text-display`、一句话副标 `--text-body-lg`、渐变 CTA 按钮「了解更多/Learn More」→ 对应产品分类页）。
   - 交互：自动 5s 切换、悬停暂停、触摸滑动、指示点/箭头（design-spec §6.7）；reduced-motion 时关闭自动播放。
2. **信任条**（静态）：一行展示认证与规模——NMPA · FDA · CE · TGA · ISO13485 · 30+ 国家 · 400+ 三甲医院。图标 + 短词，桌面横排、移动横向滚动。
3. **产品中心入口**（静态卡网格）：10 个一级分类卡（图 + 分类名 + 一句话简介），空分类卡片右上角加胶囊标签「筹备中/Coming Soon」（`--color-warning-600` 字、`--color-warning-50` 底），点击仍进入分类页（页内说明）。
4. **关于我们摘要**（静态）：左图（企业介绍图）右文（摘要 3 行 + 「了解更多」次按钮 → 关于我们页）。
5. **公司宣传视频**（VideoPlayer，client:visible）：深底 `#0B2B52` 区块，标题「走进天泓 / About Tianhong」，16:9 播放器居中（最大 960px）。
6. **新闻动态预览**（静态）：**当前为空 → 首页不渲染该区块**（空态不在首页展示；新闻栏目保留但首页不暴露空列表，见 §5 备注）。
7. **联系引导条**（静态）：浅青底 `--color-accent-100`，「需要产品资料或报价？」+ 主按钮「联系我们」→ 联系页。

异常态：轮播图缺失 → 该卡隐藏，指示点同步减少；全部缺失 → Hero 降级为静态品牌区（渐变底 + 三品牌名横排）。

## 2. 关于我们 `/zh/about/` `/en/about/`

区块顺序：

1. **页横幅**（Banner）：背景图 + H1「关于我们/About Us」+ 面包屑。
2. **公司简介**（静态长文）：正文区最大 760px；首段 `--text-body-lg`，正文 `--text-body`；配图右浮动（桌面）/ 顶部通栏（移动）。
3. **企业发展历程**（HistoryTimeline，静态增强）：**原站为单张图片**——新版保留图片为主，下方补一条可访问的文本时间轴列表（从图转录，需内容方提供年份文案；无文案时仅展示图片 + alt 全文描述）。图片可点击进灯箱看大图。
4. **荣誉资质**（CertificateCarousel，client:visible）：中文 9 张 / 英文 8 张证书，卡片 3:4，桌面 4 张一屏、移动 1.5 张露出暗示可滑；点击进灯箱；左右箭头 + 指示点。
5. **全球布局**（静态）：简述 30+ 国家、国内十余城市销售网络；用数据卡（数字 `--text-h2` `--color-primary-600` + 标签）。
6. **联系引导条**：同首页 §1-7。

异常态：证书图加载失败 → 该卡显示占位 + 证书名称文字仍可读；时间轴文案缺失 → 只渲染图片区块（不渲染空列表）。

## 3. 产品中心

### 3.1 一级分类页 `/zh/products/` `/en/products/`

1. 页横幅 + H1「产品中心/Products」+ 面包屑。
2. **分类卡网格**：10 个一级分类（同首页 §1-3 卡片规范，含「筹备中」标签）。
3. 底部联系引导条。

### 3.2 二级分类列表页 `/zh/products/[category]/` `/en/products/[category]/`

1. 页横幅（分类主题图）+ H1 = 分类名 + 面包屑（首页 › 产品中心 › 分类名）。
2. **左侧分类导航**（CategoryNav，≥1024px 显示，宽 240px）：一级分类树，当前分类高亮（左 3px `#00B3A6` 边条 + `--color-primary-50` 底），子分类缩进 16px；移动折叠为页横幅下的横向滚动 Tab 条。
3. **分类简介**：有简介文案的分类（如低温热塑支具系列）在列表上方显示，`--text-body` 最大 760px。
4. **产品卡网格**（ProductGrid）：产品卡（图 + 名称 + 一句话适应症摘要）。
   - **空分类（15 个）**：空态面板——「该系列产品资料整理中，欢迎联系我们获取」+「联系我们」次按钮 + 「索取产品彩页」文字链（→ 下载页）。**不显示假产品占位**。
5. **在线留言表单**（Form，client:load）：该分类专用留言（表单隐藏字段记录来源分类 slug），字段与交互见 design-spec §6.4。

### 3.3 产品详情页 `/zh/products/[category]/[product]/`（12 个真实产品）

1. 面包屑（首页 › 产品中心 › 分类 › 产品名）。
2. **产品主区**：左图右文（≥1024px，图区占 5/12）/ 上下堆叠（移动）。产品图可点击进灯箱；多图时缩略图条（60×60px，当前 2px 主色边框）。
3. **产品信息**：H1 产品名 + 适应症/用途正文 + 要点列表（✓ 图标 `--color-success-600`）。
4. **相关视频**（如有匹配视频元数据）：视频卡横排，点击进视频页或页内播放。
5. **同分类其他产品**：3 卡横排（移动横滚）。
6. **在线留言表单**：隐藏字段记录产品 slug。

异常态：产品图缺失 → 占位图 + 名称；视频元数据缺失 → 不渲染 §4。

## 4. 资源

### 4.1 下载页 `/zh/resources/downloads/`

1. 页横幅 + H1「下载/Downloads」+ 面包屑。
2. **下载卡列表**（3 项 PDF）：下载卡（design-spec §6.3）整卡为 `<a download>`；标注文件大小与格式；中英文文件分别对应各语言站（盘点 §4.4）。
3. 空态（理论兜底）：「暂无下载资料」。

### 4.2 视频列表 `/zh/resources/videos/` 与子栏目 `/zh/resources/videos/[category]/`

1. 页横幅 + H1「视频/Videos」+ 面包屑。
2. **栏目标签条**：低温热塑板材 / 患者固定 / 宠物康复（中）；Physical Rehabilitation / Patient Immobilization / Pet Rehabilitation（英）。当前栏目主色下划线。
3. **视频卡网格**：视频卡（海报 + 标题 + 时长 + 播放图标）；点击进**页内模态播放**（灯箱式播放器，design-spec §6.7）——不跳详情页。
4. **空栏目**（中文宠物康复）：空态面板「视频制作中，敬请期待」。
5. 英文站视频较多（16+）：每页 12 个 + 「加载更多」次按钮（无 JS 时分页链接）。

## 5. 新闻动态 `/zh/news/` `/en/news/`

- 现状：原站中英文新闻列表均空、三个子栏目 404（盘点 §7-1）。
- **新版结构**：保留单一「新闻动态」列表页（不再建三个 404 子栏目入口，页脚同步移除）。
- 页面：页横幅 + H1 + **空态面板**（「暂无动态，敬请期待 / No news yet. Stay tuned.」+ 订阅引导文字链「如需了解最新进展，欢迎联系我们」）。
- 结构预留：列表数据来自 `data/news.json`，日后新增条目即自动渲染卡片列表（日期 `--text-small` `#7B8794` + 标题 + 摘要 2 行截断）。
- **首页不渲染新闻预览区**（避免首屏暴露空栏目）。

## 6. 联系我们 `/zh/contact/` `/en/contact/`

区块顺序：

1. 页横幅 + H1「联系我们/Contact Us」+ 面包屑。
2. **联系信息卡组**（桌面 2×2 / 移动单列）：电话（点击 `tel:`）、邮箱（`mailto:`）、地址（纯文本 + 「查看地图」外链）、公众号（二维码 96×96px + 名称）。电话注意中英文差异（英文站含分机 -2018，盘点 §4.5）。
3. **在线留言表单**（全字段版）：称呼 / 公司* / 邮箱* / 名* / 姓* / 手机 / 内容；校验、错误、成功、降级见 design-spec §6.4。
4. **社交链接**：LinkedIn / Facebook 图标链（新窗口，`rel="noopener"`）。

## 7. 特殊页面

- **404**：双语 404 页（按请求路径语言前缀渲染对应语言，默认中文）。
- **搜索页**：见 §0.3。

## 8. 全站交互清单（组件 ↔ 页面映射）

| 组件 | 出现页面 | 岛屿策略 |
|---|---|---|
| Carousel 品牌轮播 | 首页 | client:visible |
| CertificateCarousel | 关于我们 | client:visible |
| Lightbox | 关于我们、产品详情 | client:idle（随触发组件加载） |
| VideoPlayer / 视频模态 | 首页、视频列表、产品详情 | client:visible |
| Form 留言表单 | 产品分类、产品详情、联系我们 | client:load |
| Search | 全站页头 | client:visible |
| LanguageSwitcher | 全站页头/抽屉 | client:load（需记忆偏好） |
| CategoryNav / ProductGrid | 产品页 | 纯静态（无 JS 可用） |

> 渐进增强底线：导航、卡片、列表、面包屑、页脚在无 JS 下完整可用（规范 §6.6、架构 §3.5）。
