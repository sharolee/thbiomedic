## 方向 A · 专业克制型（Clinical Trust）

**气质**：干净、可信、克制——把信息层级和阅读秩序做到位，让医院科室与经销商第一眼感到"这是一家靠谱的专业厂商"。

**可参考的真实网站**：

- Össur 奥索（全球假肢/康复支具龙头，同行业最直接对标）：https://www.ossur.com
- Stryker 史赛克（医疗科技巨头，白底 + 品牌蓝 + 克制点缀）：https://www.stryker.com

**关键设计参数**：

| 项 | 值 |
|---|---|
| 主色 | `#0D8FB5`（Logo 青蓝）；深色档 `#0A6E88` / `#063845` |
| 强调色 | `#E75306`（Logo 橙红，仅主 CTA 与小面积点睛） |
| 中性色 | `#1B2A32` / `#3D4F59` / `#71838D` / `#CBD6DB` / `#E3EAEE` / `#F4F8FA` |
| 字体 | 英文 Inter / 中文 PingFang SC·微软雅黑（与 Logo 无衬线气质一致） |
| 字号阶梯（桌面） | 48 / 32 / 22 / 18 / 16 / 14px，行高标题 1.25、正文 1.75 |
| 间距/栅格 | 4px 基数（4→96px 十档）；容器 1200px；12 列栅格 |
| 圆角/阴影 | 4 / 8 / 12px；轻阴影 `0 4px 14px rgba(6,56,69,.10)` |
| 动效强度 | **弱**：仅悬停变色/位移 3px，180ms |

**适用理由**：受众是医院采购、科室主任、经销商——决策链保守，信任感优先；Össur 式的"专业克制"是骨科康复行业的国际通行语言。落地风险最低，与执行层既有规范（design-spec）最接近，迁移成本最小。

**风险**：视觉个性偏弱，"先进感"需要通过图片质量与微动效补足，否则容易显得普通。

**相对原站的升级点**：原站深蓝 + 密集栅格 + 无层级区分；A 方向换成 Logo 原生青蓝（比原站蓝更亮、更现代），留白放大一档（区块 64–96px），建立 4 级字号阶梯与统一卡片语言，首屏即可读清"三条品牌线"。

**文件**：`docs/design/prototypes/direction-a/`（`index.html` + `styles.css`）

## 方向 B · 科技未来型（Med-Tech Dark）

**气质**：深墨青底 + 青蓝辉光，大字号宣言式 Hero——把"材料科技"作为第一叙事，传递"先进、精准、面向未来"。

**可参考的真实网站**：

- Intuitive 直觉外科（达芬奇手术机器人，深底科技医疗标杆）：https://www.intuitive.com
- Globus Medical（骨科植入物科技公司，深色 + 渐变光效）：https://www.globusmedical.com

**关键设计参数**：

| 项 | 值 |
|---|---|
| 底色 | `#04181F` / `#06222E` / `#0B3040`（青调深墨，非纯黑） |
| 主色 | `#0D8FB5` + 提亮档 `#2FB6DC`；品牌渐变 `#0D8FB5→#2FB6DC→#7FE0C3` |
| 强调色 | `#E75306` / `#FF6B1F`（数字、角标、高能点缀） |
| 文字 | 高亮 `#EAF6FA` / 正文 `#9FBCC8` / 弱化 `#6C8B97` |
| 字体 | Inter + PingFang/雅黑；数字用 Inter tabular-nums |
| 字号阶梯（桌面） | 60 / 38 / 22 / 18 / 16 / 14px |
| 间距/栅格 | 4px 基数；容器 1280px；12 列栅格；Hero 区 140px 大留白 |
| 圆角/阴影 | 12 / 20px；辉光 `0 0 40px rgba(47,182,220,.25)`；玻璃拟态卡片 |
| 动效强度 | **中强**：悬停浮起 + 辉光 + 渐变描边，220ms |

**适用理由**：项目诉求含"先进"；B 方向把"65°C 低温激活、3 分钟塑形"这类材料参数提升为 Hero 级叙事，科技感最足，适合展会大屏与海外客户第一印象。深底上 Logo 的实测对比度反而更好（识图结论 §5-2）。

**风险**：① 医疗采购决策者偏保守，深底大页面对部分国内医院客户可能"太炫"；② 长文阅读（公司简介等内页）需配浅底段落（原型中新闻区已演示深浅交替），纯深底不可读长文；③ 对图片/视频素材质量要求高，素材跟不上时深底会放大廉价感。

**相对原站的升级点**：原站是传统 CMS 表格感页面，B 方向直接跳到"科技公司发布会"层级——宣言式 Hero、参数化信任指标、玻璃拟态产品卡，是三方向中与原站差异最大、最"看得出进化"的方向。

**文件**：`docs/design/prototypes/direction-b/`（`index.html` + `styles.css`）

## 方向 C · 温暖人文型（Warm Human-centered）

**气质**：暖米白底 + 大圆角 + 胶囊按钮，橙红从点缀升为主强调——叙事主角从"材料"换成"康复中的人与动物"，有温度、有对话感。

**可参考的真实网站**：

- Hinge Health（数字肌骨康复独角兽，暖色 + 大圆角人文风标杆）：https://www.hingehealth.com
- Sword Health（同类数字康复平台，对话式文案 + 柔阴影）：https://www.swordhealth.com

**关键设计参数**：

| 项 | 值 |
|---|---|
| 底色 | `#FBF6EF` / `#F5EDE1` / `#EBDFCC`（暖米白体系） |
| 主色 | `#0D8FB5`（信任锚点，图标/标签/数据带用） |
| 强调色 | `#E75306` / `#C94505`（主 CTA、eyebrow、悬停——用量三方向中最大） |
| 文字 | `#33302B` / `#55514A` / `#8A847A`（暖调灰，不用冷灰） |
| 字体 | Inter + PingFang/雅黑；正文行高 1.85（三方向中最松） |
| 字号阶梯（桌面） | 46 / 34 / 22 / 19 / 16 / 13px |
| 间距/栅格 | 4px 基数；容器 1120px（最窄，聚焦内容） |
| 圆角/阴影 | 16 / 24 / 32px 大圆角；柔阴影 `0 14px 40px rgba(85,70,50,.14)` |
| 动效强度 | **中**：悬停浮起 + 轻微旋转（-0.3°）手账感，260ms |

**适用理由**：① 公司三条品牌线里有"宠物康复"——情感化叙事天然契合，与竞品拉开差异；② 康复的终点是"人重新站起来"，人文叙事与 Logo"旭日/海面"意象（希望、启程）高度同频；③ 海外数字康复赛道（Hinge/Sword）已验证该语言对 C 端与保险雇主受众有效。

**风险**：① 对 2B 医院采购场景偏"软"，权威感需靠认证徽章与数据带补足（原型已做徽章式信任条 + 青蓝数据带）；② 暖米白底对印刷品与部分老旧显示器色准略敏感；③ 若客户希望"稳重第一"，C 可能被认为不够正式。

**相对原站的升级点**：原站零情感化表达、冷蓝企业风；C 方向引入暖色系、场景化文案（"它们不会说疼"）、手账式新闻卡与故事化数据带——是三方向中品牌人格最鲜明的方向。

**文件**：`docs/design/prototypes/direction-c/`（`index.html` + `styles.css`）

## 推荐项与理由

**推荐：方向 A 为主基调，吸收 B 的 Hero 叙事手法。**

理由：受众（医院科室、经销商、海外代理）决策链保守，信任优先，A 是行业通行语言且落地风险最低；同时把 B 方向"参数化 Hero + 渐变品牌光效"的手法移植进 A 的首屏（如 Hero 增加 65°C/3min 参数条），可在不牺牲可读性的前提下表达"先进"。C 的人文语法则建议在"宠物康复"品牌线页面局部采用，不必全站铺开。

> 若客户更看重"一眼惊艳/展会效果"，选 B；若客户希望主打宠物康复 C 端市场或强调品牌温度，选 C。

## 需要客户确认的取舍点

1. **主方向三选一**（A / B / C，或"A 为主 + 局部融合"的推荐方案）。
2. **深色底接受度**：选 B 意味着接受首页大面积深色，需确认主要国内客户群不排斥。
3. **橙红用量**：A 点 sparingly / B 中量 / C 大量——橙色在多大规模上出现，本质上是"专业感 ↔ 亲和力"的取舍。
4. **Logo 矢量源文件**：现有 logo.png 仅 188×54 位图，三个方向 Hero/页脚放大使用都会发虚，建议向客户索取 SVG/AI 源文件（识图结论 §5-3）。

| 页头滚动态 / 滚动显现 / 数字滚动 | 悬浮透明页头滚动后加玻璃底；reveal 与计数同 A-plus | 无依赖 |

### 对选型的影响

- A-plus 证明：**A 方向也能承载"先进感"**——视频 + 轻粒子已足够亮眼，且不伤可读性与医疗克制气质，落地成本低（无三方依赖）。
- B-plus 是三方向中视觉冲击力上限最高的方案，适合展会/大屏/海外第一印象；代价是引入 three.js CDN 依赖与 WebGL 兼容面（已内置降级）。
- 两版均含完整降级：无 JS / 无 WebGL / reduced-motion / 视频加载失败都有静态兜底。
