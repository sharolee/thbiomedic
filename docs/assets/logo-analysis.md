## 0. 方法与可信度声明（先读这一段）

本报告的结论由**两条独立证据链**交叉得出，互相印证：

| 证据链 | 手段 | 覆盖 |
|---|---|---|
| **① 真实目视（视觉复核轮）** | 运行时的多模态模型直接查看图片，并将原图放大 4–8 倍输出到白底 / 深底预览复核 | 图形符号内容、字体衬线属性、字重、整体气质 |
| **② 程序化像素测量** | Pillow / NumPy 逐像素：OCR（RapidOCR PP-OCRv4）、连通域、行投影、alpha 直方图、逐行 alpha 剖面、对比度计算 | 尺寸、色值、占比、透明底、笔画量级（可复现数字） |

> 背景：本任务首轮由无视觉能力的运行时完成，只能给出像素测量，并留有 3 项"无法目视、拒绝推断"的结论。本**视觉复核轮**由具备图像输入能力的运行时补上目视证据链，逐项闭合。

**逐项置信度**：

- **高（目视 + 像素双重确认）**：图形符号的构成、文字内容「天泓医疗 / ONESKY」、字体为无衬线、字体粗细分层、透明底、主色色值。
- **中（目视确认，无客观仪器佐证）**：画面意象的解读（"日出 / 海面"），属看图的主观读法，已标注为"意象解读"，不等于设计意图。
- **低（明确不下结论）**：字体具体字库来源、图形符号的正式命名。

### 1.2 图形符号（左半区，x 1–95）——已目视

**符号 = 上方一个橙色"旭日"圆盘 + 下方一道青色上扬弧线**，合起来读作"旭日 / 日出海面"的意象。

- **上方圆盘**：一个橙色实心圆，但**由横向条纹构成**——整张圆盘的色相只有一个（`#E75306`），深浅差异全部来自**逐行 alpha 条纹**：横向明暗交替，周期约 3–4 px，alpha 在 0 / 63 / 127 / 191 / 255 之间跳变（x=48 竖向剖面实测）。观感像一轮带光晕/扫描线质感的太阳，或"分层堆叠的球体"。圆盘下缘有一处 1 px 的抗锯齿残点。
- **下方弧线**：一道青色（`#0D8FB5`）的**平滑上扬弧**，两端向下、中间隆起，横跨整个左半区宽度（约 95 px），像地平线 / 海面 / 波浪的一道弧。它位于圆盘正下方，与圆盘之间留有空隙。

像素测量（与目视一致）：

| 块 | 包围盒（绝对坐标） | 尺寸 | 像素面积 | 面积/包围盒 | 形态 |
|---|---|---|---|---|---|
| 旭日圆盘 | (31, 4) → (65, 33) | 34 × 29 | 679 | 0.69 | 横纹圆盘，偏上居中偏左 |
| 底部弧线 | (1, 36) → (96, 50) | 95 × 14 | 492 | 0.37 | 横向长弧，几乎铺满左半区宽度（右端尾收在 x95） |

| 碎点 B | (45, 2) → (52, 3) | 7 × 1 | 7 | – | 抗锯齿残留 |

（上表为 8 邻域连通域实测：10 个连通域 = 圆盘 1 + 弧线 1 + 中文 2 + 英文 4 + 2 px 级碎点 2。）

行投影（有墨的行）：y2（1 行碎点）→ y4–32（圆盘）→ y33 空 → y34（1 行碎点）→ y35 空 → y36–49（弧线）。即符号是**上圆盘 + 下弧线**两段式，二者之间隔 2 行空隙（y33、y35）。两处碎点各为 1 px 高、水平落在圆盘 x 范围（31–64）的正上方/正下方，是笔画边缘的抗锯齿残留，不是独立元素。

颜色构成（左半区 x1–95 的不透明像素）：橙红系 697 px（**58.6%**）、青蓝系 491 px（**41.3%**）——圆盘橙、弧线青，橙略多。

- 中文行比英文行**高约 25%**（22 px vs 18 px），且左边界对齐（均约 x 98）、右边界对齐（均约 x 187）→ 标准的双语锁版排版：中文主标在上、英文副标在下，上下齐边。

### 1.4 字体气质——已目视

**两行均为无衬线字体（sans-serif），无衬线特征明确**（目视可见笔画端部为方形/平切，无衬线小脚；笔画粗细均匀）。

| 项 | 上行「天泓医疗」 | 下行「ONESKY」 |
|---|---|---|
| 字形高度 | 22–23 px | 17–18 px |
| 笔画最粗处（腐蚀迭代） | **≈5 px** | **≈3 px** |
| 笔画覆盖率（墨/包围盒） | 0.57 | 0.53 |
| 字体类别（目视确认） | 无衬线（黑体类），笔画端部平切 | 无衬线（等线/几何 grotesque 类），全大写 |
| 字重定级（目视 + 测量） | **≈Bold / 中黑**，充当主标 | **≈Medium / SemiBold**，充当副标 |
| 视觉结论 | 笔画明显更粗 → 偏粗/中黑量感，主标 | 笔画更细、字面更开、字距紧 → 中等量感，副标 |

- 字体整体气质：**现代、中性、企业感**；中文用黑体类加粗承担主信息，英文用干净的全大写 grotesque 承担品牌名，两行上下对齐，规整克制。
- 仍**不下结论**：无法确认为哪一套具体字库（如思源黑体 / 微软雅黑 / Helvetica 等），像素级无法反推字库来源。

## 2. 主色提取

对全部不透明像素按精确 RGB 统计：

| 角色 | HEX | RGB | 说明 |
|---|---|---|---|
| **主色（青蓝）** | `#0D8FB5` | (13, 143, 181) | 全部文字 + 符号的青色弧线 |
| **点缀色（橙红）** | `#E75306` | (231, 83, 6) | 仅符号的橙色旭日圆盘 |

- 在 alpha = 255 的 969 个像素中**只有上述两个色值**——不存在第三种填充色、无渐变填充、无描边色。
- 圆盘的"深浅变化"不是第三个颜色，而是**同一橙色叠加逐行 alpha 条纹**（见 §1.2），属于透明调制，不是调色板里的新色。
- 其余 93 个不同色值全部来自抗锯齿（半透明像素，`0<α<255` 共 2 364 个）：它们都是这两个主色与透明底混合的中间态，不是设计用色。另有 19 个纯黑像素、alpha 全部为 1（占全图 0.19%），是文字边缘的抗锯齿残余，**不是设计色**。

## 3. 目视确认结论（首轮 3 项"未验证"已闭合）

| 原未验证项 | 视觉复核结论 | 依据 |
|---|---|---|
| 图形符号具体描绘的是什么？ | **橙色横向条纹圆盘（读作"旭日/太阳"）+ 下方青色上扬弧线（读作"地平线/海面/波浪"）**，整体是"旭日 / 日出海面"意象；符号区**不含文字、不含可辨认的具象物体或动物**，是抽象几何构成 | 目视 4–8× 放大预览（白底 + 深底）；圆盘为单一橙色 + 横向 alpha 条纹，弧线为单一青色平滑弧 |
| 中英文是否衬线？ | **两行均为无衬线**（中文黑体类、英文全大写 grotesque），非衬线体 | 目视笔画端部平切、无衬线小脚 |
| 字重正式定级？ | 中文主标 ≈**Bold / 中黑**，英文副标 ≈**Medium / SemiBold** | 目视粗细分层 + 笔画像素测量（§1.4） |

## 4. 品牌基线总结

- **标志类型**：横版"图形符号 + 双语字标"组合标（combination mark），188 × 54，内容 187 × 48，比例约 3.48:1。
- **图形意象**：上方橙色横纹"旭日"圆盘 + 下方青色上扬弧线，构成"日出 / 海面（地平线）"意象；抽象、几何、无具象细节。
- **色彩语言**：扁平双色——青蓝 `#0D8FB5` 为主（约八成墨量），橙红 `#E75306` 为点缀（约两成），无第三色、无渐变填充、无描边。青蓝承担医疗/科技的可信、洁净感，橙红承担活力与识别点。
- **文字层级**：中文「天泓医疗」为主标（更大、更粗，黑体），英文「ONESKY」为副标（更小、更开、紧排大写 grotesque）——双语结构，以中文名为主、英文名为辅。
- **底与可移植性**：真透明底（67.2% alpha=0），可叠放在任意背景；alpha 有 250 个不同取值，边缘做了抗锯齿，非硬边裁切。
- **一致性**：头部与页脚、中文站与英文站用的是**同一张图**（服务端同 ETag、同字节），全站标志零变体。

## 5. 对 SHAR-50 主风格设计的启示

1. **色板可直接沿用**：主色 `#0D8FB5`、强调色 `#E75306`。派生灰阶/中性色建议从青蓝降饱和取，避免纯黑正文与橙红冲突。
2. **单色变体（反白）的实际需求**：实测对比度——青蓝 `#0D8FB5` 对白底 **3.74:1**、对近黑 `#111111` **5.05:1**；橙红 `#E75306` 对白底 **3.72:1**、对近黑 **5.07:1**。也就是说**该 logo 在深色底上的可读性其实优于白底**（两个色都是中间明度，深底反差更大），并不存在"深底上会糊"的问题；反而是用纯白/浅色底时对比偏弱（约 3.7:1，低于正文 AA 4.5:1，仅够大字号）。若新站要在深色区块上放 logo，直接用原图即可；若追求极简或单色印刷，可另行派生纯白描形版本——**是否派生由设计总监定，本报告只提供事实**。
3. **尺寸不足，建议索取矢量源文件**：188 × 54 是位图，PNG 声明 dpi 144。用于导航栏（高 32–48 px）够用，但 hero、打印彩页、大屏展示放大 2 倍以上会明显发虚。**建议向客户索取 SVG/AI 源文件**，不要自行插值放大。
4. **双语不需要两套 logo**：图内已同时含中英文，`/zh/` 与 `/en/` 共用 `logo.png` 即可，省掉一套资源与切换逻辑。
5. **补齐原站缺失项**：原站 `<img>` 无 `alt`、无 `width/height`、全站无 favicon —— 新站需补 `alt="广州天泓医疗科技有限公司"`（en: `Guangzhou Tian Hong Medical Technology Co., Ltd.`）、显式尺寸（防 CLS），以及 favicon/manifest。
